How do I install the tools?

After you have installed the Quantower platform, you can unzip the files directly into the Quantower installation folders:

For strategies:

Copy the strategy folder from the zip file and place it here:

[install-path]\Quantower\Settings\Scripts\Strategies

Example for AVWAP Mean Reversion Strategy:

D:\Programs\Quantower\Settings\Scripts\Strategies\AVWAPReversion
For indicators:

Copy the indicator folders from the zip file and place it here:

[install-path]\Quantower\Settings\Scripts\Indicators

Example for AVWAP Indicator:

D:\Programs\Quantower\Settings\Scripts\Indicators\AVWAP

The common execution layer and thuss all the strategies, are created with a "live-first" principal. They are an accumulation of 2 years of work making strategies run stable in a live environment. Can I run many strategies simultaneuously?

Yes! You can create how many strategy instances as you want. As long as you have enough computing power. You can run many instances of the same strategy at the same time. And you can also run many instances of another strategy, all at the same time. As long as each instance are on either different brokers/exhanges or different symbols on the same broker/exchange.

Can I use the strategies with ProjectX?

OBS! We are currently testing and tweaking the ProjectX execution, and it will be completed very soon. Yes you can run on the ProjectX API from within Quantower, but there is currently a caveat in that you can only do 1-legged trades. Which means you cannot have 3 different TakeProfits with automatic handling from the execution layer. That is because ProjectX only allows 1 server-side SL/TP pair on a position. You could however do this manually, like you have the base SL/TP, and then just create different TP orders manually. This will probably change in the future, and some day all of our strategy and execution features will work 100% with ProjectX as well.

What happens if I loose connection while the strategies are running?

All of the SL/TP pairs are server-side, so worst case is that maybe the trailing logic doesnt work, but the protective StopLosses and TakeProfits are server-side at the broker/exchange. Usually when the connection is re-established the strategies will pick up again. But we recommend that you also set max daily loss limits in the broker softwares if available. This is possible on for example the "Rithmic R Trader Pro" application when using that together with Quantower, and also if using ProjectX. You do need to do some research and testing with these things. Any losses that might occur are your responsibility and we cannot take responsibility or reimburse anything.
